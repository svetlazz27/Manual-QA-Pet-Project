
Project Description

1. Project Overview

Project Name: Manual QA Pet Project  
Project Type: Educational QA Portfolio  
Testing Focus: Manual Testing, UI Testing, API Testing, SQL, Test Design  
Project Status: In Progress

2. Project Purpose

The purpose of this project is to develop practical software testing skills through independent learning and hands-on exercises.

The project simulates basic QA workflows, including requirements analysis, test documentation, test execution, defect identification, API testing, and database validation.

3. Project Objectives

- Develop practical Manual QA skills.
- Learn to analyze requirements and identify potential risks.
- Create and maintain test documentation.
- Design and execute test cases and checklists.
- Identify, document, and analyze software defects.
- Practice functional, UI, smoke, regression, and exploratory testing.
- Learn API testing using Postman.
- Practice SQL queries and database validation.
- Learn version control using Git and GitHub.
- Develop basic UI test automation skills using JavaScript and Playwright.

4. Testing Activities

| Area | Planned Activities |
|---|---|
| UI Testing | Functional, smoke, regression, and exploratory testing |
| Test Documentation | Test plans, checklists, test cases, and bug reports |
| Bug Hunting | Identifying, documenting, and analyzing defects |
| API Testing | HTTP methods, status codes, request and response validation |
| Test Design | Equivalence partitioning and boundary value analysis |
| SQL Testing | SELECT queries, filtering, JOIN, and data validation |
| UI Automation | JavaScript fundamentals and automated UI tests with Playwright |

5. Tools and Technologies

- Test Management: Qase, Kaiten
- API Testing: Postman
- Browser Testing: Chrome DevTools
- Database: SQL
- Version Control: Git, GitHub
- Code Editor: Visual Studio Code
- Programming Language: JavaScript
- Automation Framework: Playwright
- Documentation: Markdown

7. Expected Results

- Build a structured QA portfolio.
- Gain practical experience in manual testing.
- Improve test design and documentation skills.
- Learn to identify and report software defects.
- Understand the fundamentals of API and database testing.
- Gain experience with Git and GitHub.

This is an ongoing educational project. Documentation, test cases, checklists, bug reports, and test results will be added as practical exercises are completed.
