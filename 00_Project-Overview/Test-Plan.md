
Test Plan

1. Introduction

1.1 Purpose

The purpose of this Test Plan is to define the testing approach, objectives, scope, resources, and activities for this educational QA project.

The document describes how testing activities will be organized and performed during practical exercises.

1.2 Project Description

This project is an educational QA portfolio focused on developing practical software testing skills.

Testing activities include web application testing, API testing, test design techniques, SQL practice, and basic test automation.

1.3 Test Objectives

The main objectives are:

- Practice different types and levels of software testing.
- Create test cases, checklists, and bug reports.
- Identify and document defects.
- Gain practical experience with testing tools.
- Develop analytical and technical skills.
