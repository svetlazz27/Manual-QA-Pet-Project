# Test Plan

## 1. Цель тестирования
Проверить основные пользовательские сценарии интернет-магазина DemoBlaze и убедиться, что ключевой функционал работает корректно: регистрация, вход, работа с каталогом, корзина и оформление заказа.

## 2. Объект тестирования
Веб-сайт DemoBlaze: https://www.demoblaze.com/

## 3. Объем тестирования (Scope)

### Входит в тестирование
- Регистрация пользователя (Sign up)
- Авторизация пользователя (Log in / Log out)
- Просмотр каталога и категорий товаров
- Просмотр страницы товара
- Добавление товара в корзину
- Удаление товара из корзины
- Оформление заказа (Place Order)
- Базовые проверки Contact / About us
- Базовые UI-проверки и сообщения об ошибках (alerts)
- Базовое API-тестирование через Postman (на уровне запрос/ответ)

### Не входит в тестирование (Out of Scope)
- Глубокое security-тестирование
- Нагрузочное / performance testing
- Автоматизированное тестирование
- Мобильное тестирование
- Проверка backend-кода и внутренней серверной реализации

## 4. Типы тестирования
- Smoke testing
- Functional testing
- Exploratory testing
- Regression testing (базовый уровень)
- UI testing
- Basic API testing (Postman)

## 5. Подход к тестированию
- Подготовить чек-листы по основным модулям.
- Подготовить тест-кейсы для критичных сценариев.
- Выполнить ручное тестирование по чек-листам и тест-кейсам.
- Выполнить базовые API-проверки в Postman.
- Зафиксировать найденные дефекты в bug-reports.
- Сформировать итоговый отчет по результатам тестирования.

## 6. Критерии начала тестирования (Entry Criteria)
- Сайт DemoBlaze доступен.
- Определены основные модули и пользовательские сценарии.
- Подготовлены тестовые данные (username/password и т.д.).
- Создана структура QA-документации в репозитории.

## 7. Критерии завершения тестирования (Exit Criteria)
- Проверены все сценарии из smoke-чеклиста.
- Выполнены тест-кейсы по ключевым модулям.
- Выполнены базовые API-проверки в Postman.
- Все найденные дефекты задокументированы.
- Подготовлен краткий test summary report.

## 8. Тестовая среда
- Тип: Web (desktop)
- Браузер: Yandex Browser
- ОС: macOS
- URL: https://www.demoblaze.com/

## 9. Артефакты тестирования
- Checklists
- Test cases
- Bug reports
- Screenshots
- API test cases (Postman)
- Test summary report

## 10. Риски
- Нестабильность demo-сайта.
- Возможные сбросы данных между сессиями.
- Различия поведения UI/alerts в разных браузерах.
- Отсутствие официального SRS/API-документации.
