# Project Description

## Название проекта
DemoBlaze

## Ссылка на продукт
https://www.demoblaze.com/

## Краткое описание продукта
DemoBlaze — это демонстрационный интернет-магазин с каталогом товаров (Phones, Laptops, Monitors), созданный для отработки пользовательских сценариев покупки. На сайте доступны регистрация и вход, просмотр карточек товаров, добавление в корзину и оформление заказа. Проект подходит для практики manual QA, включая функциональное, UI, smoke/regression и базовое API-тестирование.

## Цель тестирования
Потренироваться в реальном QA-процессе: анализ продукта, формирование тестовых артефактов, проверка ключевых пользовательских сценариев, оформление баг-репортов, базовое API-тестирование и подведение итогов тестирования.

## Роли пользователей
- Гость (неавторизованный пользователь)
- Зарегистрированный пользователь

## Основные модули (что есть на сайте)
1. Главная страница и навигация
2. Каталог / категории товаров
3. Страница товара
4. Корзина (Cart)
5. Оформление заказа (Checkout / Place Order)
6. Регистрация и вход (Sign up / Log in)
7. Выход (Log out)
8. Contact / About us (страницы и форма)

## Что входит в практику тестирования (на pet-проекте)
- Smoke testing (минимальная проверка критичных сценариев)
- Functional testing (основные пользовательские сценарии)
- UI / проверка отображения и удобства интерфейса
- Exploratory testing (неформальные проверки)
- Regression testing (проверка, что ранее рабочее не сломалось)
- Basic API testing (проверка запросов и ответов через Postman)

## Что пока не делаю глубоко (Out of Scope)
- Глубокое security-тестирование
- Нагрузочное / performance testing
- Автоматизированное тестирование
- Мобильное тестирование
