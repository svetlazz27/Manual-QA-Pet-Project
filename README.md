# Manual QA Pet Project

## Project Description
Manual QA portfolio project based on testing the DemoBlaze e-commerce demo website.
The goal is to practice real QA workflow: requirements analysis, test documentation, bug reporting, API and SQL checks.

## Technology Stack
- Manual testing
- Postman
- SQL
- Markdown / Excel

## Project Structure
- `docs/` — project description, test plan, reports
- `test-cases/` — test cases by modules
- `checklists/` — testing checklists
- `bug-reports/` — found defects
- `api/` — API test cases and Postman collection
- `sql/` — SQL practice queries
- `screenshots/` — evidence for bugs and test results

## Testing Types
- Smoke testing
- Functional testing
- Regression testing
- Exploratory testing
- API testing
- SQL testing

## Tools Used
- GitHub
- Postman
- Browser DevTools
- SQL client
- Markdown
